Angalia frontend design

The app at phone width and in a desktop browser. Use the toggles to preview dark mode, and to see the alternative direction and old name that were considered. The notes under the mockups record what changed in the code and the decisions made.

This is the design of the current release, v3.0.0, live on Render and Netlify since 6 October 2026: direction A (Plum & Gold), dark mode and the name Angalia. These mockups were drawn before it was built; details that changed along the way:

  • Direction B and the Overwatch name were alternatives considered during review; only A and Angalia were built.
  • The Wolfram result sits in a fixed-height scrolling window at full card width ("Click to enlarge").
  • The picked photo has Change photo and Remove buttons; Change photo pulses once a result arrives.
  • On desktop the photo stays in the left card through the whole lookup, and the right card shows "Looks like" and the result.
  • Guests see Create account and Leave guest mode in Settings instead of Sign out.
  • The lookup counts are examples; the real daily allowance is set on the server (5 by default).

What changes in the code

  • Tailwind v4 via @tailwindcss/vite. The 400-line index.css becomes about 40 lines of @theme tokens. Its specificity workarounds, like .wrapper form button.photo-source-button, disappear because styles live on each element.
  • One layout, two breakpoints. A single column on phones becomes two columns from about 900px (Tailwind's lg:). The bottom tab bar becomes the top nav on the same breakpoint, so they're one component.
  • Same flow, clearer screens. Pick a photo, tap Analyse, confirm the guess, then see the result, exactly as today. Phones show one step at a time. Desktop keeps the input and the current step side by side. The only change to the button is its label, from "Analyse My Nutrition!!" to "Analyse photo".
  • Settings tab. It holds the usage meter, the App ID dialog, Appearance (System / Light / Dark, remembered on the device) and Sign out. The "See Settings below" error becomes a link to the tab.
  • Real external link. The Wolfram link uses target="_blank" rel="noreferrer". In a browser it opens a new tab. In the installed app, Android and desktop open it in the default browser, and on iOS it opens an in-app Safari sheet.
  • Native <dialog> for the enlarged result and the App ID form. This gives focus trapping, Escape to close and aria-modal without a library.
  • Inline spinner. It replaces the loader GIF fetched from s3.amazonaws.com/static.mlh.io.
  • Tests. They query by role, text and input[type="file"], not by class. The test that clicks "Analyse" only needs its button name updated.

Decisions

  1. Direction: A, Plum & Gold.
  2. Dark mode: shipped in v3.0.0, with System / Light / Dark under Settings → Appearance.
  3. UI kit (shadcn/ui, Radix): skipped. The browser's built-in <dialog> handles the app's pop-ups.
  4. Name: Angalia, replacing Overwatch and GrubWatch.
  5. Lookup flow: unchanged from before the redesign. A photo needs Analyse, then the "Looks like" check; typed or spoken text goes straight to the result.
