# Angalia frontend

The Vite + React app (installable as a PWA) for Angalia. It talks only to the API server in the repo root.

Run it from the **repo root** with `npm run dev`, which starts this frontend and the API server together on matching ports. See the main docs:

- [Development](../docs/development.md): setup, `frontend/.env`, running, tests (`npm test` here runs Vitest), project layout
- [How it works](../docs/how-it-works.md): the photo, text and voice flows, and the API this frontend calls
- [Deployment](../docs/deployment.md): Netlify settings
- [Troubleshooting](../docs/troubleshooting.md)
